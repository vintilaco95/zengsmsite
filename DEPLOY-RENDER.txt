ZEN GSM — deploy static (Next.js export)

================================================================================
DE CE „NU SE SCHIMBĂ NIMIC” PE ZENGSM.RO
================================================================================
Modificările sunt în GitHub; dacă în browser tot vezi site-ul vechi (.html la fiecare
pagină, fără _next în sursă), problema este APROAPE ÎNTOTDEAUNA la Render, nu la cod:

  • Publish Directory NU este „out” (ex: încă e „.” sau gol).
  • Build Command lipsește sau nu e „npm ci && npm run build”.
  • Serviciul Static nu e legat de repo-ul cu Next / folosește alt branch.
  • render.yaml nu e aplicat: serviciul creat manual NU ia automat rutele din fișier
    până nu folosești Blueprint sau nu copiezi manual redirecturile în Dashboard.

================================================================================
VERIFICARE ÎN 20 SECUNDE (fără Render)
================================================================================
1. Deschide https://zengsm.ro/ → click dreapta → „View Page Source” (sau sursa paginii).

2. Caută în text (Ctrl+F):
   • data-zengsm-engine="next-export-out"
   • și/sau  /_next/static/

   Dacă NU apar: live-ul NU e build-ul Next din folderul „out”. Repetă pașii Render de mai jos.

3. Cu build corect, „/vanzare-telefon.html” este redirectat către „/” (pagina a fost eliminată) — vezi render.yaml și postbuild.

================================================================================
SETĂRI OBLIGATORII ÎN RENDER (Static Site)
================================================================================
Build Command:     npm ci && npm run build
Publish Directory: out

(Optionale) Environment → Build-time:
  NEXT_PUBLIC_SITE_URL=https://zengsm.ro
  (sau https://www.zengsm.ro dacă așa ții domeniul canonic)

După modificare: Save → Manual Deploy (Clear build cache dacă ai dubii).

================================================================================
RUTE (redirect .html + articole blog dinamice)
================================================================================
Fișierul render.yaml din repo descrie redirecturile și rewrite-ul /blog/:slug → /blog-articol/.

Dacă NU folosești Blueprint:
  Copiază manual din render.yaml, în Dashboard → Static Site → Redirects / Rewrites,
  aceleași reguli (altfel .html rămâne în URL).

================================================================================
Build local (test înainte de push)
================================================================================
  npm install
  npm run build
  npx serve out -l 3000

Deschide http://localhost:3000/ — în sursă trebuie să apară data-zengsm-engine și _next.

===============================================================================
Articole TechBlog: /blog/<slug>/ → conținut luat live de pe e-gsm la fiecare vizită
(shell out/blog-articol/index.html + scripts/techblog-article.js), fără redeploy.
