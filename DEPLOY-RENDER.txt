ZEN GSM — deploy static (Next.js, ca ajutortechnologia)

Build local:
  npm install
  npm run build
  → output în directorul `out/`
  npm run start  (serve local pe port 3000)

Render.com → Static Site:
  Build Command:  npm ci && npm run build
  Publish directory:  out

Variabile de mediu (opțional, în Dashboard):
  NEXT_PUBLIC_SITE_URL=https://zengsm.ro
  TECHBLOG_API_BASE=https://www.e-gsm.ro
  TECHBLOG_BLOGGER_SLUG=andreea

Articolele TechBlog sunt pre-randate la build (`/blog/[slug]`). După articole noi pe e-gsm.ro, rulează un redeploy ZEN GSM ca să apară în site.

Blueprint: `render.yaml` (redirecționări de la vechile URL-uri *.html către rute fără .html).

Fișiere HTML vechi pentru extracție la build: `legacy-pages/`. Nu se publică; conținutul este înglobat în paginile Next.
