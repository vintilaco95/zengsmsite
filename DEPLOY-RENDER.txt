ZEN GSM — deploy static (Next.js export)

Build local:
  npm install
  npm run build
  → `next build` + pagina articol TechBlog în `out/blog-articol/index.html` (încărcare live din API la fiecare vizită).
  npm run start  (serve `out/` pe port 3000)

Render.com → Static Site:
  Build Command:  npm ci && npm run build
  Publish directory:  out
  (Verifică că serviciul folosește **Blueprint** sau aceleași setări — dacă publish e încă „.”, vei vedea în continuare URL-uri .html vechi.)

Variabile de mediu (Build + Runtime pentru postbuild):
  NEXT_PUBLIC_SITE_URL=https://zengsm.ro   (sau https://www.zengsm.ro dacă așa e canonicul tău)

Rute:
  Paginile site (/, /servicii, …) sunt din Next.
  /blog/lista → client fetch (techblog-feed.js).
  /blog/<slug> → rewrite CDN → `blog-articol/index.html` → `techblog-article.js` citește mereu articolul de pe e-gsm (fără redeploy la articol nou).

Fișiere: `legacy-pages/` (sursă la build); `render.yaml` — redirect *.html → rute curate + rewrite articole.
